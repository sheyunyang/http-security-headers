# HTTP安全头工具

> 分类：Web安全 ｜ 编号：项目 13 / 67 / 300 ｜ 生成日期：2026-10-06

## 简介
粘贴响应头自动评分并列出缺失项，一键生成 Nginx/Apache/IIS 修复配置；Cookie 安全属性分析。

## 功能清单
- HTTP 安全头分析
- 安全响应头配置生成
- Cookie 安全分析

## 使用方法
1. 直接用浏览器（Chrome / Edge）双击打开 `index.html`，无需安装任何东西。
2. 所有计算均在本地浏览器完成，断网也能用，数据不会上传到任何地方。
